# ADR-021: The reviewer moves to Gemini 4 Hydrogen, a different series from the builder

## Status
Accepted (2026-11-22). Amends [ADR-008](ADR-008.md) (independent reviewer) and [ADR-019](ADR-019.md).

## Context
Run [44980211177](https://github.com/RishabhDev01/tinydb/actions/runs/44980211177) (run 17) was the first full build on Gemini. Guard, spec, design, implement + test and release all passed in **2 min 28 s**, and PR #17 had green CI.

The review job then used `qwen/qwen3.8-27b` on **Groq's free tier: 8K tokens per minute**.
- Each reviewer turn re-sends the diff and the code read so far, about 6–7k tokens with the reply allowance, so the reviewer got **about one turn per minute**.
- Almost every turn waited about 50 s on a 429.
- It also read `table.py` in 60–120-line chunks. With up to 25 turns, one review takes **about 20–25 minutes**, about ten times longer than everything before it.

The maintainer asked to move the reviewer to Gemini too, but to a **different model series** from the builder.

## Decision
- **The reviewer is `gemini-4-hydrogen`.** The builder and planner are `gemini-3.8-flash`, a different generation and series.
  - Tier 1 on this account: **1K requests/min, 2M tokens/min, 10K requests/day** (AI Studio → Rate Limit).
  - Price: $1.50 input / $7.50 output per 1M tokens (Google's pricing page).
- **Fallback:** `gemini-4-hydrogen` → `qwen/qwen3.8-27b` (Groq). The reviewer never falls back to the builder's model family.
- **The review job now receives `GEMINI_API_KEY`.** It is still read-only on GitHub (ADR-008): `contents: read`, and no push or comment rights.
- **Reviewer `max_tokens` 1800 → 3000,** because Gemini counts thinking tokens as output and a long verdict could be cut off.
- **The LLM judge stays on qwen (Groq).** It makes one small call per spec, which the free tier handles easily, and it stays on a different vendor from the planner whose output it checks.

## Options considered
- **Keep qwen and give the reviewer the changed code up front** (as ADR-016 did for the builder). This reduces turns, but each turn is still capped at 8K tokens/min. It is worth doing later anyway.
- **Use the same Gemini model as the builder.** Rejected: a reviewer that is the same model as the author shares its blind spots (ADR-008).
- **Use Gemini 4 Neon or Argon.** They are stronger but 1.3–2× the price; Hydrogen is enough for a first pass.

## Consequences
- **Independence is weaker** than with a different vendor: same company, different model series and generation. The report should say this and use it as a variable in experiment E1 (reviewer model).
- **Cost** per review round is roughly $0.10–0.15 (about 60k input and 5k output tokens). It counts toward the ₹1,000/month cap.
- **Expected time** per review: a few minutes instead of about 25.
- **Tested** with a mocked transport:
  - `gemini-4-hydrogen` goes to Google with `max_tokens` 3000 and `reasoning_effort` low;
  - a 3,600 s 429 falls back to Groq qwen;
  - the builder's fallback is unchanged;
  - the workflow's review job has `GEMINI_API_KEY`.

  The tinydb suite passes.
